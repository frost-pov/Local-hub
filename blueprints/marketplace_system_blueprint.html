Tech stack — what to actually use

Backend
Supabase PostgreSQL Auth Edge Functions
No custom Node/Express at V1. Supabase handles everything.
Payments
Daraja API STK Push M-Pesa B2C
STK Push for customer payments. B2C for vendor payouts later.
Storage & CDN
Supabase Storage Cloudflare CDN
Start with Supabase Storage. Move to R2 when you scale.
Frontend
Vanilla HTML/CSS/JS Vercel
You know this stack. Don't switch to React. Ship faster.
Notifications
WhatsApp Business API Manual fallback OK
Skip USSD and SMS for now. WhatsApp is what Nairobi uses.
Maps
Skip V1 Leaflet later
Delivery address = text field for now. Maps are Phase 2.
